# Voice Bridge

Windows এর যেকোনো অ্যাপে বাংলা ভয়েস টাইপিং। Voice In এক্সটেনশন যেই Google ইঞ্জিন ব্যবহার করে, ঠিক সেটাই ব্যবহার করে, কিন্তু টেক্সট বসে ব্রাউজারের বাইরে।

## কীভাবে কাজ করে

Chrome এর ভেতরে একটা বিল্ট-ইন Web Speech API আছে যেটা সরাসরি Google এর speech engine এ যায়। বাংলার জন্য এটাই সবচেয়ে ভালো এবং ফ্রি। Voice In এর পুরো শক্তি ওখানেই।

Voice Bridge তিনটা অংশে চলে:

1. `voicebridge.py` লোকাল সার্ভার চালায় (127.0.0.1:8756)
2. Chrome এ একটা ছোট উইন্ডো খোলে যেটা শোনে এবং লেখা চিনে
3. চেনা লেখা Python এ ফেরত আসে, Python সেটা Windows `SendInput` (KEYEVENTF_UNICODE) দিয়ে টার্গেট উইন্ডোতে টাইপ করে দেয়

ক্লিপবোর্ড ব্যবহার হয় না, Enter চাপা হয় না। তাই ভুল করে মেসেজ সেন্ড হয়ে যাওয়ার সমস্যা নেই।

## টার্গেট উইন্ডো

Voice Bridge মনে রাখে আপনি শেষবার কোন অ্যাপে কাজ করছিলেন। সেটাই টার্গেট, এবং উইন্ডোর নিচে সবসময় দেখাবে "Typing into ..."।

আপনি Voice Bridge উইন্ডোর দিকে তাকিয়ে কথা বললেও লেখা ওই টার্গেটেই যাবে, কারণ টাইপ করার ঠিক আগে ফোকাস নিজে থেকে ফিরিয়ে দেওয়া হয়। এটা না চাইলে `RESTORE_FOCUS = False` করে দিন, তখন টার্গেটে ক্লিক করে থাকতে হবে।

## সেটআপ

দরকার: Windows 10/11, Python 3.9+, Chrome অথবা Edge। কোনো pip প্যাকেজ লাগবে না।

1. পাঁচটা ফাইল একই ফোল্ডারে রাখুন: `voicebridge.py`, `recognizer.html`, `favicon.ico`, `icon.png`, `start.bat`
2. `start.bat` ডাবল ক্লিক করুন
3. যেই অ্যাপে লিখবেন সেখানে একবার ক্লিক করুন, তারপর হটকি চেপে কথা বলুন

## হটকি

| কাজ | ডিফল্ট |
|---|---|
| শুরু / বন্ধ | Ctrl + Alt + M |
| ভাষা পাল্টানো (bn-BD / en-US) | Ctrl + Alt + L |

হটকি বদলাতে `voicebridge.py` এর CONFIG ব্লকে লিখুন, যেমন:

```
HOTKEY_TOGGLE = "ctrl+alt+m"
HOTKEY_TOGGLE = "ctrl+shift+d"
HOTKEY_TOGGLE = "alt+f9"
HOTKEY_TOGGLE = "pause"
HOTKEY_TOGGLE = "scrolllock"
```

`pause` বা `scrolllock` এর মত একক কী প্রায় কখনোই অন্য অ্যাপের সাথে সংঘর্ষ করে না, আর এক আঙুলেই চাপা যায়।

কোনো হটকি অন্য অ্যাপ দখল করে রাখলে কনসোলে পরিষ্কার ওয়ার্নিং দেখাবে।

## সেটিংস

`voicebridge.py` এর উপরের CONFIG ব্লকে:

| সেটিং | মানে |
|---|---|
| `DEFAULT_LANG` | মূল ভাষা। `bn-BD` অথবা `bn-IN` |
| `ALT_LANG` | হটকি দিয়ে যেটায় সুইচ করবেন |
| `RESTORE_FOCUS` | Voice Bridge ফোকাসে থাকলে টার্গেটে ফোকাস ফিরিয়ে দেবে কিনা |
| `TYPE_INTERIM` | `True` করলে কথা বলার সাথে সাথেই আধা-চেনা লেখা বসবে, পরে ঠিক হবে। বাংলায় interim result অনেক বদলায়, তাই ব্যাকস্পেস দিয়ে মুছে আবার লিখবে |
| `ADD_TRAILING_SPACE` | প্রতি বাক্যের পরে স্পেস |
| `CHUNK_DELAY_MS` | কোনো অ্যাপ অক্ষর ড্রপ করলে `5` বা `10` করে দিন |

## জেনে রাখা ভালো

- Voice Bridge উইন্ডোটা মিনিমাইজ করা যাবে, কিন্তু বন্ধ করলে চলবে না। Chrome ব্যাকগ্রাউন্ড ট্যাব থ্রটল করে, তাই উইন্ডোটা খোলা রাখুন
- ইন্টারনেট লাগবে, কারণ Google এর ইঞ্জিন ক্লাউডে
- টার্গেট অ্যাপ যদি অ্যাডমিন হিসেবে চলে, Windows এর UIPI টাইপিং ব্লক করবে। তখন `start.bat` ও Run as administrator দিয়ে চালান। এই অবস্থায় উইন্ডোতে লাল লেখায় কারণ দেখাবে
- বাংলায় Google অটো যতিচিহ্ন দেয় না, দাঁড়ি নিজে দিতে হবে

## যদি কিছু কাজ না করে

**লেখা কোথাও যাচ্ছে না**
উইন্ডোর নিচের লাইনটা দেখুন। "No target yet" মানে এখনো কোনো অ্যাপে ক্লিক করেননি। লাল লেখা মানে Windows ব্লক করেছে, কারণটাও ওখানেই লেখা থাকবে।

**"This browser has no speech engine"**
Firefox এ খুলে গেছে। Chrome বা Edge এ `http://127.0.0.1:8756/` খুলুন।

**অক্ষর উল্টাপাল্টা বসে**
`CHUNK_DELAY_MS = 10` করে দিন।

**কিছুক্ষণ পর নিজে থেকে থেমে যায়**
Chrome নিজেই সেশন শেষ করে দেয়, স্ক্রিপ্ট অটো রিস্টার্ট করে। বারবার থামলে মাইক ইনপুট লেভেল খুব কম কিনা দেখুন।
