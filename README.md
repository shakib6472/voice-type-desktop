# Voice Bridge

Windows এর যেকোনো অ্যাপে বাংলা ভয়েস টাইপিং। Voice In এক্সটেনশন যেই Google ইঞ্জিন ব্যবহার করে, ঠিক সেটাই ব্যবহার করে, কিন্তু টেক্সট বসে ব্রাউজারের বাইরে।

## কীভাবে কাজ করে

Chrome এর ভেতরে একটা বিল্ট-ইন Web Speech API আছে যেটা সরাসরি Google এর speech engine এ যায়। বাংলার জন্য এটাই সবচেয়ে ভালো এবং ফ্রি। Voice In এর পুরো শক্তি ওখানেই।

Voice Bridge তিনটা অংশে চলে:

1. `voicebridge.py` লোকাল সার্ভার চালায় (127.0.0.1:8756)
2. Chrome এ একটা ছোট উইন্ডো খোলে যেটা শোনে এবং লেখা চিনে
3. চেনা লেখা Python এ ফেরত আসে, Python সেটা Windows `SendInput` (KEYEVENTF_UNICODE) দিয়ে টার্গেট উইন্ডোতে টাইপ করে দেয়

ক্লিপবোর্ড ব্যবহার হয় না, Enter চাপা হয় না। তাই ভুল করে মেসেজ সেন্ড হয়ে যাওয়ার সমস্যা নেই।

## সেটআপ

দরকার: Windows 10/11, Python 3.9+, Chrome অথবা Edge। কোনো pip প্যাকেজ লাগবে না।

1. ফাইলগুলো একই ফোল্ডারে রাখুন
2. `install.bat` একবার ডাবল ক্লিক করুন

এটা Start Menu আর Desktop এ শর্টকাট বানিয়ে দেবে, আর জিজ্ঞেস করবে Windows চালু হলেই Voice Bridge চালু হবে কিনা।

**Taskbar এ পিন করতে:** Start চেপে "Voice Bridge" লিখুন, রেজাল্টে রাইট ক্লিক করে **Pin to taskbar**।

শর্টকাটগুলো `pythonw.exe` দিয়ে চালায়, তাই কোনো কালো টার্মিনাল উইন্ডো খোলে না। শর্টকাট মুছতে `uninstall.bat`।

প্রথমবার Chrome মাইক্রোফোনের অনুমতি চাইবে, একবার **Allow** দিলেই হবে। Voice Bridge এর নিজের আলাদা Chrome প্রোফাইল আছে, তাই সেটা মনে থাকবে।

## ব্যবহার

উইন্ডোতে তিনটা জিনিস: মাইক বাটন, ভাষার দুটো বাটন (বাংলা / EN), আর ডানদিকে ছোট **i** বাটন।

- যেই অ্যাপে লিখবেন সেখানে একবার ক্লিক করুন, তারপর হটকি চেপে কথা বলুন
- **কথা বলার সাথে সাথেই লেখা বসতে থাকে।** Google শোনা কথা বারবার শুধরায়, তাই লাইনের শেষের দিকটা বদলাতে দেখবেন। যতটুকু বদলেছে শুধু ততটুকুই আবার লেখা হয়
- থামলেই বাক্য শেষ ধরে নিয়ে একটা **দাঁড়ি** বসে যায়
- **i** চাপলে নিচে দেখাবে লেখা কোন অ্যাপে যাচ্ছে। আবার চাপলে লুকিয়ে যাবে, পছন্দটা মনে থাকে
- মাইক **সবুজ** মানে শুনছে, **লাল** মানে সমস্যা। কারণ জানতে মাইকের উপর মাউস রাখুন, অথবা **i** চেপে দেখুন
- **উইন্ডো বন্ধ করলেই Voice Bridge বন্ধ** হয়ে যায়। মিনিমাইজ করলে চলতে থাকে
- একবারে একটাই কপি চলে। চালু থাকা অবস্থায় শর্টকাট চাপলে নতুন কপি না খুলে পুরনো উইন্ডোটাই সামনে আসে

## মুখে পাংচুয়েশন

বলার মধ্যেই এই শব্দগুলো বললে শব্দের বদলে চিহ্নটা বসবে:

| বলুন | বসবে |
|---|---|
| দাঁড়ি / দাড়ি / পূর্ণচ্ছেদ | । |
| কমা | , |
| প্রশ্নবোধক | ? |
| বিস্ময়বোধক | ! |
| কোলন / সেমিকোলন / হাইফেন | : ; - |

ইংরেজিতে `comma`, `full stop`, `question mark`, `exclamation mark`।

কোনোটাই Enter চাপে না, তাই ভুল করে মেসেজ চলে যাওয়ার ভয় নেই। শব্দটা আলাদা করে বললে তবেই চিহ্ন হবে, "দাঁড়িপাল্লা" লিখলে সেটা অক্ষত থাকবে।

## হটকি

| কাজ | ডিফল্ট |
|---|---|
| শুরু / বন্ধ | Ctrl + Alt + M |
| ভাষা পাল্টানো (bn-BD / en-US) | Ctrl + Alt + L |

হটকি বদলাতে `voicebridge.py` এর CONFIG ব্লকে লিখুন, যেমন:

```
HOTKEY_TOGGLE = "ctrl+alt+m"
HOTKEY_TOGGLE = "ctrl+shift+d"
HOTKEY_TOGGLE = "alt+f9"
HOTKEY_TOGGLE = "pause"
HOTKEY_TOGGLE = "scrolllock"
```

`pause` বা `scrolllock` এর মত একক কী প্রায় কখনোই অন্য অ্যাপের সাথে সংঘর্ষ করে না, আর এক আঙুলেই চাপা যায়।

কোনো হটকি অন্য অ্যাপ দখল করে রাখলে মাইক লাল হয়ে যাবে আর কারণটা **i** এর নিচে লেখা থাকবে।

## সেটিংস

`voicebridge.py` এর উপরের CONFIG ব্লকে:

| সেটিং | মানে |
|---|---|
| `DEFAULT_LANG` | মূল ভাষা। `bn-BD` অথবা `bn-IN` |
| `ALT_LANG` | হটকি দিয়ে যেটায় সুইচ করবেন |
| `RESTORE_FOCUS` | Voice Bridge ফোকাসে থাকলে টার্গেটে ফোকাস ফিরিয়ে দেবে কিনা |
| `TYPE_INTERIM` | কথা বলার সাথে সাথে লেখা বসবে কিনা। `False` করলে থামার পর পুরো বাক্য একসাথে বসবে, শান্ত লাগে কিন্তু প্রায় দুই সেকেন্ড বেশি লাগে |
| `ADD_END_MARK` | থামলে দাঁড়ি বসবে কিনা |
| `END_MARK` | কোন ভাষায় কোন চিহ্ন। বাংলায় `।`, ইংরেজিতে `.` |
| `SPOKEN_PUNCTUATION` | মুখে বলা শব্দ থেকে চিহ্নের তালিকা। নিজের শব্দ যোগ করতে পারেন |
| `ADD_TRAILING_SPACE` | প্রতি বাক্যের পরে স্পেস |
| `CHUNK_DELAY_MS` | কোনো অ্যাপ অক্ষর ড্রপ করলে `5` বা `10` করে দিন |
| `WINDOW_SIZE` | উইন্ডোর সাইজ। শুধু প্রথমবার কাজে লাগে, এরপর আপনি টেনে যে সাইজ করবেন Chrome সেটাই মনে রাখবে |
| `QUIT_GRACE_SEC` | উইন্ডো বন্ধ হওয়ার কত সেকেন্ড পরে Voice Bridge বন্ধ হবে |
| `SINGLE_INSTANCE_WAIT_SEC` | আগের কপি বন্ধ হওয়ার জন্য কতক্ষণ অপেক্ষা করবে |

## জেনে রাখা ভালো

- উইন্ডোটা মিনিমাইজ করা যাবে, কিন্তু খোলা রাখতে হবে। Chrome ব্যাকগ্রাউন্ড ট্যাব থ্রটল করে
- ইন্টারনেট লাগবে, কারণ Google এর ইঞ্জিন ক্লাউডে
- টার্গেট অ্যাপ যদি অ্যাডমিন হিসেবে চলে, Windows এর UIPI টাইপিং ব্লক করবে। তখন Voice Bridge ও Run as administrator দিয়ে চালান। এই অবস্থায় মাইক লাল হয়ে কারণ দেখাবে
- Google বাংলায় কোনো যতিচিহ্ন দেয় না। দাঁড়িটা Voice Bridge নিজে বসায়, বাকি চিহ্ন মুখে বলে দিতে হবে

## যদি কিছু কাজ না করে

সবার আগে `voicebridge.log` দেখুন, ওটা এই ফোল্ডারেই তৈরি হয়। কনসোল উইন্ডো নেই, তাই সব বার্তা ওখানেই যায়।

কনসোল দেখে ডিবাগ করতে চাইলে `start.bat` দিয়ে চালান, তখন টার্মিনালে সব দেখা যাবে।

**লেখা কোথাও যাচ্ছে না**
**i** চেপে নিচের লাইনটা দেখুন। "No target yet" মানে এখনো কোনো অ্যাপে ক্লিক করেননি। লাল লেখা মানে Windows ব্লক করেছে, কারণটাও ওখানেই লেখা থাকবে।

**"This browser has no speech engine"**
Firefox এ খুলে গেছে। Chrome বা Edge এ `http://127.0.0.1:8756/` খুলুন।

**অক্ষর উল্টাপাল্টা বসে**
`CHUNK_DELAY_MS = 10` করে দিন।

**কিছুক্ষণ পর নিজে থেকে থেমে যায়**
Chrome নিজেই সেশন শেষ করে দেয়, স্ক্রিপ্ট অটো রিস্টার্ট করে। বারবার থামলে মাইক ইনপুট লেভেল খুব কম কিনা দেখুন।

**Taskbar এর পিনে ক্লিক করলে খালি Chrome খুলছে**
চলন্ত উইন্ডোটা taskbar থেকে পিন করলে Windows আসলে Chrome কে পিন করে। ওই পিনটা সরিয়ে দিন, তারপর Start চেপে "Voice Bridge" খুঁজে সেই রেজাল্টে রাইট ক্লিক করে **Pin to taskbar** দিন।

**লেখার শেষে প্রতিবার দাঁড়ি চাই না**
`ADD_END_MARK = False` করে দিন।

**কথা বলার সময় লেখা বদলাতে থাকে, অস্বস্তি লাগে**
`TYPE_INTERIM = False` করে দিন। তখন থামার পর পুরো বাক্য একসাথে বসবে।

**উইন্ডোর সাইজ অদ্ভুত লাগছে**
কিনারা ধরে টেনে যে সাইজ চান করে নিন, Chrome মনে রাখবে। একদম শুরুর অবস্থায় ফিরতে চাইলে `C:\Users\<নাম>\.voice-bridge-profile` ফোল্ডারটা মুছে দিন।
